# Crypto Hourly Desk

Upload the contents of this folder to a private HTTPS static host, then open the URL in Safari on iPhone and choose **Share → Add to Home Screen**.

The package contains no portfolio, wallet, liability, credential, or order data. Each artifact includes a `social_context` block built from CoinGecko trending, Google News RSS, and Reddit RSS where available. Each coin also receives a 0–100 combined opportunity score: market/tradability inputs are weighted 70% and social/news context 30%. Social direction can change a neutral market into bullish or bearish research, while source health and capture time remain visible. The score is a confidence ranking, not a calibrated probability or trade authorization. Opening the app and Quick scan refresh all three schedule artifacts, refresh all displayed Kraken quote sets, use the latest shared social/news collector snapshot, and retry transient requests up to three times. Deep scan repeats that synchronized refresh and force-fetches every candidate's OHLC history for day trading, weekly trading, and 3+ months with bounded concurrency, retries, and completed/failed reporting; it enforces a 15-second minimum full pass so a nominal deep scan cannot appear complete immediately. Social/news collection remains server-side and artifact-based because GitHub Pages cannot run private RSS collectors directly in every browser; scheduled collector commits now trigger Pages deployment. The full local command center and its scheduled refresh jobs remain in `dashboard/` and `jobs/`.

The app now fails closed with `DATA STALE — NO SIGNAL` unless every displayed candidate has a fresh Kraken public Ticker quote, a valid USD spot pair, a compatible 24-hour range, and a complete quote batch no older than 120 seconds. Prices are labeled as live only after that gate succeeds; the summary shows quote source, age, coverage, artifact age, and build ID. The hourly and daily task wrappers refresh both the dashboard artifacts and the mobile artifacts. A service-worker cache version change forces clients to activate the freshness-gated build.

All LONG/SHORT labels are research-only. Short-side research remains blocked for execution unless margin permission is independently verified.
